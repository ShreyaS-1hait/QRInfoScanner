# 📱 QRInfoScanner

A Unity-based Android application that scans QR codes using the device camera and displays information about the corresponding object.

## 🚀 Features

- 📷 Real-time QR code scanning
- 🖼️ Displays object image
- 📝 Shows object name
- 📖 Displays object description
- ⚡ Fast QR detection using ZXing.Net
- 📱 Built for Android devices

---

## 🛠️ Tech Stack

- **Game Engine:** Unity 6
- **Language:** C#
- **QR Scanner:** ZXing.Net
- **Platform:** Android

---

```
Assets

```

---

## 📸 How It Works

1. Launch the application.
2. Grant camera permission.
3. Point the camera at a QR code.
4. The QR code is decoded.
5. The application displays:
   - Object Image
   - Object Name
   - Object Description
